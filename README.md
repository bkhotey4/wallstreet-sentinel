# WallStreet Sentinel — 全球跨資產風險情報 Discord Bot

> 📡 **情報站模式**：`settings.yaml` 的 `portfolio.enabled: false`，不讀取任何持倉。GitHub 網站的建置與設定見 [SITE.md](SITE.md)。

用 24/7 即時數據監控**整個金融圈**（美/歐/亞/新興股市、美債、信用、私募信貸、銀行、匯率套息、商品、加密、波動率、選擇權部位、總經與流動性），以機構級量化模型評估系統性風險，並由 Claude（Gemini 備援）扮演首席策略師給出可執行的判斷。

## 和舊版最大的不同

| | 舊版 | Sentinel |
|---|---|---|
| 架構 | `discord_bot.py` 單檔 658KB | 資料層 / 分析層 / AI 層 / Discord 層分離 |
| 門檻 | 寫死（如「HYG 偏離 -1%」） | 每個因子對**自身 3 年滾動歷史**做 z-score，會隨市場環境自動調整 |
| 崩盤預測 | 手工打分 | **實證回測**：「歷史上壓力指數在這個區間時，標普之後跌 X% 的頻率」，並列出基準機率與獨立事件數 |
| 壓力測試 | 假設跌幅 | 用 2008、2020、2022、2024 日圓拆倉等**真實歷史價格**重播你的持倉 |
| AI | 可能幻覺 | AI 只能使用 DATA PACK 中的數字，缺資料必須寫「資料缺」 |
| 設定 | 散落在程式碼 | 全部在 `settings.yaml` |

## 監控內容

- **系統性壓力指數 SSI（0–100）**：42 個因子、10 大區塊 — 信用（HY/CCC/投資級 OAS、HYG/IEF、區域銀行）、私募信貸（BDC、槓桿貸款 BKLN、另類資管 BX/APO/ARES）、波動率（VIX 期限結構、VIX9D/VIX、VVIX、MOVE、標普實現波動）、流動性（NFCI、聖路易壓力指數、聯準會淨流動性、銀行準備金）、利率（2 年期急跌、曲線、10 年實質利率、30 年期）、匯率套息（美元、日圓、澳幣/日圓、人民幣、韓元）、股市結構（200 日線、廣度、板塊相關性、小型股相對強弱、AI 龍頭集中度）、全球新興（EM 債、歐洲銀行、銅金比）、商品加密（黃金避險買盤等）、景氣就業（初領失業金、Sahm 衰退指標）
- **崩跌機率**：21 日跌 5%、63 日跌 10%、126 日跌 20%；同時考慮「壓力水準」與「SSI 20 日升溫速度」（動態百分位門檻，樣本少時自動收斂），並以「高於/低於歷史基準 X 倍」呈現
- **總經象限**：成長 × 通膨（金髮女孩/再通膨/停滯性通膨/通縮衰退）+ 風險偏好 + 流動性擴張/收縮
- **SPX 選擇權 Gamma**：造市商 GEX、零 Gamma 翻轉點、Call/Put 牆、Put/Call 比
- **持倉**：即時損益、β、歷史 VaR/CVaR、各股風險貢獻、有效檔數、歷史危機重播
- **情報**：13 個新聞源（CNBC、MarketWatch、Bloomberg、FT、Fed、ECB、BOJ、CoinDesk、Google News 風險/地緣/中文）去重 + 風險評分；SEC EDGAR 持股公告（8-K、內部人、13D、增資、延遲申報）
- **行事曆**：FOMC（即時抓 Fed 官網）、CPI/非農/GDP/PCE 等（FRED）、持股財報
- **情緒/加密**：CNN 恐懼貪婪、加密恐懼貪婪、BTC 主導率、穩定幣供給（流動性）、永續合約資金費率與未平倉量

## 新增功能（2026/10/03）：堤防下一次金融衝擊

- **衝擊雷達 `/shock`**：每個風險區塊同時看「水準」和「近 20 日升溫速度（歷史百分位）」，並算出該區塊對『63 日內大跌』的歷史預警力（AUC）。再把區塊組成 6 條傳導路徑（信用事件、利率／債市衝擊、套息拆倉、波動率／槓桿去化、景氣衰退、商品／地緣能源），給出「點火分數」——告訴你下一次衝擊最可能從哪裡來
- **股債背離**：信用／利率／流動性／新興壓力領先股市恐慌 ≥15 分時提示（歷史上這種背離之後的大跌機率會一併列出）
- **模型可信度**：走步外樣本回測（只用當時已知資料預測，含 embargo 避免洩漏），給出樣本外 AUC 與相對基準的 Brier 技能分；並逐一檢討歷史上每次標普≥10% 的回檔，模型有沒有在高點前預警、領先多久。**誠實揭露：鑑別力差的情境（AUC<0.6）會標示『接近隨機』**
- **戰情總控台 `/command`（僅擁有者）**：風險階段（正常／留意／戒備／防禦）＋ 各項分數來源 ＋ 衝擊路徑 ＋ 避險有效性 ＋ 持倉集中度 ＋ 資料健康 ＋ 事件日曆。階段是規則式打分（SSI 水準、崩跌機率倍數、傳導路徑、股債背離、避險失靈），每一分都看得到原因；升階立刻私訊，降階需低於進入門檻 2 分以上（避免來回震盪）
- **風險劇本**：依階段自動產生行動清單（目標 β、優先減碼名單、避險成本提示、再進場條件）
- **避險失靈偵測**：股債 60 日相關係數轉正、20 日內『股債雙殺日』≥3、股票跌≥1% 時長債與黃金同跌比例≥50% → 週內限發一次警報
- **流動性行事曆**（併入 `/calendar`）：四巫日／月選擇權到期（遇假日自動提前）、VIX 到期日、月／季底再平衡、美債 10/20/30 年標售（TreasuryDirect）；重要事件前一天提醒
- **資料健康警報**：SSI 涵蓋率 <90% 或核心資料源停擺（重啟 15 分鐘後才檢查）→ 私訊
- **集中度警報**：單一持股>25%、風險貢獻>30%、主題（AI半導體 45%／AI合計 60%／核能小型股 15%）、β>1.5 → 每週最多一次，並給出需要減碼多少
- **警報去重**：帶日期／事件 ID 的警報改為「一次性」，不再每 4 小時重複推播同一件事
- 設定在 `settings.yaml` 的 `health` / `concentration` / `shock` / `playbook` 區塊

## 新增功能（2026/10/04）：特徵實驗室、週報、持倉 X 光、台股與可靠性

- **特徵實驗室**：每 6 小時用走步外樣本回測（年度擴張視窗＋embargo）檢驗 13 個候選特徵（VIX 期限結構、VVIX、SKEW、MOVE、200 日均線以上比例、信用動能、銀行相對強弱…）能否改善崩跌預測。**採用門檻很嚴**：AUC 增益 ≥0.02、至少 60% 的年份變好，且要贏過「時間位移安慰劑」（防止多重檢定撿到雜訊）。沒通過就不採用，並照實顯示；通過的另做等滲（isotonic）校準。結果在 `/command` 第 5 頁

- **週報 `/weekly`**：每週日 20:00 自動推播（`weekly_report` 設定）——本週風險變化、警報回顧、持倉表現、下週事件；`weekly.flag` 可手動觸發
- **FOMC 聲明比對 `/fomc`**：自動抓最新與前一次聲明，逐句比對新增／刪除並由 AI 判讀語氣（鷹／鴿）；決議日自動推播
- **`/ask` 對話記憶**：記住最近 3 輪問答（45 分鐘），可追問；`/ask reset` 清除
- **持倉 X 光 `/xray`（僅擁有者）**：有效獨立押注數（ENB，用 PCA）、相關性叢集、多因子情境（利率 +100bp、美元 +10%、標普 −20%、半導體額外 −20%、滯脹）、波動停損線（ATR×3，跌破 3% 以上權重的持股私訊）、事件曝險、目標波動縮放
- **避險升級 `/hedge`**：新增「賣權價差」與「領口（collar）」成本與損益比較
- **台股**：融資餘額（TWSE MI_MARGN，單日與近 5 日變化，大減＝斷頭賣壓；解析採防禦式，格式不符會在 /status 顯示 `twse_margin` 異常而不會亂報）、台積電 ADR 溢價
- **可靠性**：Yahoo 缺漏的美股/ETF 報價自動由 Stooq 補（`stooq_backup`）；每日備份 `sentinel.db` 到 `data_cache/backups/`（保留 7 份，`backup.keep`）；選用的本機唯讀儀表板（`web.enabled: true` → http://127.0.0.1:8787，只綁本機）
- 設定在 `settings.yaml` 的 `lab` / `weekly_report` / `xray` / `backup` / `web`

## 新增功能（2026/10/08）：情報融合——金融分析 × 金融情報 × 總經 × 風險判斷

- **情報融合 `/intel`**（公開；`ai:True` 加上 AI 研判，僅擁有者）：把三種證據合成一個可追溯的綜合風險判斷
  - **新聞 → 傳導路徑**：每則新聞依關鍵字分到衝擊雷達的 6 條路徑（信用事件、利率／債市衝擊、套息拆倉、波動率／槓桿去化、景氣衰退、商品／地緣能源），依風險分數與時間衰減（半衰期 12 小時）計算熱度；「停火、紓困、降息」等緩和字眼另計，不會被當成風險
  - **熱度對自身歷史**：每 30 分鐘把各路徑熱度存進 SQLite，與自己過去 30 天比較百分位（地緣新聞本來就多，不會永遠是「熱」）。累積不足 1 天時以絕對熱度估計並標註
  - **新聞 × 價格**：確認（新聞與價格同時示警）、敘事領先（只有新聞，等價格確認）、無聲壓力（只有價格，常被低估）、平靜
  - **三大支柱**：量化（SSI，唯一有回測）50%、總經（象限＋一個月漂移＋淨流動性＋風險偏好）25%、情報（新聞熱度）25%；顯示三方一致度與信心，並列出每一項證據（證據帳本）與確認／轉向條件（觀察清單）
- **總經漂移**：象限同時與一個月前比較，標示成長／通膨的變化方向與是否已轉換象限
- **新警報**（邊緣觸發）：某路徑變成『確認』、綜合風險升到「高」、總經象限轉換（每週一次）
- **AI**：DATA PACK 新增『情報融合』段，所有 AI 研判必須區分『確認／敘事領先／無聲壓力』
- 設定在 `settings.yaml` 的 `intel` 區塊（權重、門檻、可覆寫各路徑關鍵字）
- **限制**：綜合分數是透明的判斷框架，不是經過回測的預測模型；新聞只看標題關鍵字，不理解語意

## 安裝

1. **重設 Discord 權杖**：Developer Portal → Bot → Reset Token
2. 填寫 `.env`（參考 `.env.example`）：`DISCORD_BOT_TOKEN`、`ANTHROPIC_API_KEY`、`FRED_API_KEY`（免費）、`DISCORD_GUILD_ID`、`OWNER_USER_ID`
3. 邀請 bot：Developer Portal → OAuth2 → URL Generator，勾選 `bot` + `applications.commands`，權限選 Send Messages / Embed Links / Read Message History
4. 雙擊 `start_sentinel.bat`（首次會自動建立 .venv 並安裝套件，再由 `watchdog.ps1` 守護 24/7 執行）
5. 在 Discord 頻道輸入 `/setchannel` 設定警報與簡報頻道
6. 開機自啟：把 `start_sentinel.bat` 的捷徑放進 `shell:startup`


## 限制（請務必了解）

- Yahoo/CBOE 為免費延遲資料（約 15 分鐘），不適合當沖
- ICE 信用利差在 FRED 只提供近 3 年，所以較早年份的 SSI 只由其他因子組成
- 崩跌機率是歷史條件頻率，不是保證；重疊視窗會讓樣本看起來比實際多，請看「獨立事件」數
- 特徵實驗室與崩跌模型的樣本外鑑別力偏弱（21 日 AUC 約 0.59、63 日約 0.55），請把它當成『風險溫度計』而非預測器
- FOMC 頁面、TreasuryDirect、TWSE 融資端點的格式無法在雲端驗證，若改版會在 /status 顯示異常
- 本工具不構成投資建議
