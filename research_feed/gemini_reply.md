### D-22：核心 PCE 3.3% 分項拆解與 AI 關聯性評估

### 1. `tools/site_crisis_track.py`：寫死門檻值數字
- **位置**：第 22 行
- **程式碼**：
  ```python
  fa += (f"樣本只有 {s['n']} 次危機，數字的不確定性很大：...門檻 55 是看過整段歷史後選的，所以這是樣本內結果。")
  ```

- **問題**：第 16 行已動態取得 `lo, hi = r["levels"][0], r["levels"][-1]`，但在說明文字中卻直接寫死常數 `門檻 55`。若後續設定檔調整壓力門檻時，此處文字將與表格中的 `lo` 產生矛盾。

- **確定度**：高。

### 2. `tools/site_twforecast.py`：未保護 None 機率值格式化
- **位置**：第 74 行
- **程式碼**：
  ```python
  pline = "｜".join(f'{_e(p["name"])} <b>{_e(p.get("prob"))}%</b>' for p in paths)
  ```
- **問題**：若 `tw_forecast.json` 中的路徑物件未定義 `prob` 鍵或傳入 `None`，`_e(p.get("prob"))` 將直接輸出字串 `"None%"`，破壞前端版面專業度。
- **建議改法**：加入安全預設：`f'{_e(p["name"])} <b>{_e(p.get("prob") or "--")}%</b>'` 或僅在有值時附加百分比符號。
- **確定度**：高。

### 3. `wsb/analytics/bonds.py`：空數列未加邊界保護引發 IndexError
- **位置**：第 36–38 行
- **程式碼**：
  ```python
  def _ago(s: pd.Series, days: int) -> Optional[float]:
      p = s[s.index <= s.index[-1] - pd.Timedelta(days=days)]
      return float(p.iloc[-1]) if len(p) else None
  ```
- **問題**：若傳入空的 `pd.Series`（例如 FRED API 抓取失敗回傳空值），直接調用 `s.index[-1]` 將立即觸發 `IndexError: index out of bounds` 異常，導致整個債券模組中斷。
- **建議改法**：
  ```python
  def _ago(s: pd.Series, days: int) -> Optional[float]:
      if s.empty:
          return None
      p = s[s.index <= s.index[-1] - pd.Timedelta(days=days)]
      return float(p.iloc[-1]) if len(p) else None
  ```
- **確定度**：高。

### 4. `tools/site_rulings.py`：寫死外部錯誤狀態文字
- **位置**：第 46 行
- **程式碼**：
  ```python
  note = ("來源：...FTC 的新聞 RSS 網址目前回 404，沒有收。...")
  ```
- **問題**：將臨時性的「FTC 網址回 404」直接硬編碼寫入公開卡片說明文字。若未來資料源修復，使用者仍會看到過時的錯誤免責聲明。
- **建議改法**：將資料源健康狀態動態由 `health.py` 判斷注入，或改為通用的來源涵蓋清單。
- **確定度**：中。
