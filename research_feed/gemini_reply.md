#### 1. `tools/site_session.py` 行 38–46：MKT_CAL 缺少台股時區且假日前 30 分鐘誤報為剛開盤
- **檔案路徑與行號**：`tools/site_session.py:38-46`


  在第 46 行透過模板置換：
  ```python

  ```
- **為什麼有問題**：
  1. 模組註解寫明此為「開盤後即時盤勢」與「台股即時盤勢」共用之瀏覽器端邏輯。但在 `__CAL__` 中只寫入了 `"America/New_York"` 的行事曆，對於 `tz = "Asia/Taipei"`，`MKT_CAL[tz]` 永遠是空字典 `{}`，導致台股國定假日（如中秋、國慶、端午、春節連假）的 `hol` 判定永遠為 `false`。
  2. 在平日遇台股放假時，`wk` 為 `false`，進入 `stale` 判斷。在開盤後的 30 分鐘內（09:00 至 09:30），因 `n.m < open + MKT_WAIT`，狀態被誤判為 `'wait'`，`mktNote` 會向使用者顯示「台股剛開盤，今天的報價還沒進來」，誤導讀者以為台股有開盤，直到 30 分鐘後才翻轉為 `'closed'`。
- **建議怎麼改**：
  在 `__CAL__` 注入台股休市行事曆（例如引入 `wsb/data/exchange_cal.py` 的台灣假日），或在 `tz === 'Asia/Taipei'` 且 `stale` 發生時，檢查是否為預定休市日，避免在放假日的開盤前 30 分鐘提示「剛開盤」。
- **確定度**：高。

#### 2. `wsb/morning.py` 行 53–54：週五早會遺漏週一總經事件（跨週末邊界截斷）
- **檔案路徑與行號**：`wsb/morning.py:53-54`
- **那一行在做什麼**：
  ```python
  today_macro = [e for e in engine.calendar.events
                 if e["date"] in (d.isoformat(), (d + timedelta(days=1)).isoformat()) and e["type"] != "earnings"]
  ```
- **為什麼有問題**：
  `d` 取的是當日交易日 `street.ny_trade_date()`。當今天是週五時，`d + timedelta(days=1)` 是週六。週六與週日通常沒有總經指標發布，因此 `today_macro` 列表為空，導致第 62 行 `extra += ["今日/明日總經事件：無（或需 FRED 金鑰）"]`。然而，隔週一早上通常有重要經濟數據（例如 ISM 製造業 PMI 或國會公開程序），晨會報告卻未涵蓋下一個營業日的總經事件。
- **建議怎麼改**：
  計算下一個交易日 `next_d`（若週五則為 `d + timedelta(days=3)`），並檢查事件日期是否在 `[d, next_d]` 區間：
  ```python
  next_d = d + (timedelta(days=3) if d.weekday() == 4 else timedelta(days=1))
  today_macro = [e for e in engine.calendar.events
                 if e["date"] in (d.isoformat(), next_d.isoformat()) and e["type"] != "earnings"]
  ```
- **確定度**：高。

#### 4. `wsb/data/taiwan_quotes.py` 行 88–91：櫃買中心行情報價跌幅解析正負號防護不足
- **檔案路徑與行號**：`wsb/data/taiwan_quotes.py:88-91`
- **那一行在做什麼**：
  ```python
  change = number(r.get("Change"))
  prev = px - change if change is not None else None
  if prev is not None and prev <= 0:
      prev = None
  symbol = code + (".TW" if tw else ".TWO")
  q = dict(price=px, prev=prev, chg_pct=(px / prev - 1) * 100 if prev else None, asof=day, ...
  ```
- **為什麼有問題**：
  櫃買中心（TPEx）的 `tpex_mainboard_daily_close_quotes` OpenAPI 在部分回傳中，跌價標的之 `Change` 欄位若包含 HTML 特殊符號或三角號 `▼`，`number()` 函式（利用 `float(str(value).replace(",", "").strip())`）在遇到非標準減號時會解析失敗返回 `None`。此時 `prev` 變為 `None`，進而導致 `chg_pct` 也為 `None`，使當天跌價上櫃個股的漲跌幅在網站上顯示為空白或遺漏。
- **建議怎麼改**：
  在 `number()` 中替換掉全形負號、特殊三角符號：
  ```python
  def number(value):
      try:
          s = str(value).replace(",", "").replace("▼", "-").replace("▲", "+").replace("−", "-").strip()
          n = float(s)
          return n if math.isfinite(n) else None
      except (TypeError, ValueError):
          return None
  ```
- **確定度**：高。
