## CODE. 程式碼改善建議（第 19 批次）
依據每小時輪替批次排程（第 19 小時，`i % 24 == 19`），針對專案程式碼進行深度靜態分析，發現下列 4 處具體 Bug：

### Bug 1: `tools/site_layout.py:99` 正則表達式與輸出字串錯位導致景氣燈號遺漏
- **檔案路徑**：`tools/site_layout.py` 第 99 行
- **問題分析**：
  在 `picks()` 函式中，程式試圖從新聞摘要提取景氣燈號數據，正則表達式寫為：
  ```python
  r"景氣燈號\S*?(黃紅|黃藍|紅|綠|藍)燈（(\d{4}-\d\d)，(\d+) 分）"
  ```
  該正則要求括號內格式必須為 `（YYYY-MM，XX 分）`。然而檢視 `tools/site_twmacro.py` 第 182 行的實際輸出格式：
  ```python
  f"一句話看懂：{e['month']} 景氣燈號{e['ico']}{e['light']}燈（{e['score']:.0f} 分，{e['mood']}）"
  ```
  日期 `{e['month']}` 位於「景氣燈號」**前面**，而括號內為 `{e['score']} 分，{e['mood']}`。因此 `site_layout.py` 的正則表達式比對永遠失敗，導致首頁大表永遠無法抓取景氣對策信號。
- **具體修復方案**：
  修改 `tools/site_layout.py` 第 99 行正則表達式，使其相容日期在前且括號內包含分數的字串結構：
  ```python
  # 修正前：
  m = re.search(r"景氣燈號\S*?(黃紅|黃藍|紅|綠|藍)燈（(\d{4}-\d\d)，(\d+) 分）", txt)
  # 修正後：
  m = re.search(r"(\d{4}-\d\d)\s*景氣燈號\S*?(黃紅|黃藍|紅|綠|藍)燈[（(](\d+)\s*分", txt)
  ```

### Bug 2: `tools/site_sessions.py:35, 42` 冬令時間硬編碼導致換日與開盤計算誤差
- **檔案路徑**：`tools/site_sessions.py` 第 35 行與第 42 行
- **問題分析**：
  在 `stale_note()` 中，美東換日計算寫為：
  ```python
  ny_d = (now - timedelta(hours=5)).date()
  ```
  此處將美東時間硬編碼為 UTC-5（冬令 EST）。當進入夏令時間 EDT（UTC-4）時，午夜前後 1 小時之換日判斷將產生錯誤。此外，在第 42 行 `next_update()` 呼叫 `us_calendar(ny_d)` 時，僅查詢單一日期的開盤狀態，若當日為週五或假日前夕，未動態向前遞增搜尋下一個有效交易日，導致回傳的「下次更新時間」仍落在休市區間內。
- **具體修復方案**：
  引入 `zoneinfo.ZoneInfo("America/New_York")` 進行動態時區換算，並在 `next_update()` 中使用遞增迴圈尋找下一個交易日：
  ```python
  # 修正後：
  from zoneinfo import ZoneInfo
  ny_now = now.astimezone(ZoneInfo("America/New_York"))
  ny_d = ny_now.date()
  ```

### Bug 3: `wsb/data/china_watch.py:60` 交易日長度誤植導致 1 年高點誤判為 5 年高點
- **檔案路徑**：`wsb/data/china_watch.py` 第 60 行
- **問題分析**：
  在 `market_view()` 中，計算指數相對高低點之欄位 `hi5` 寫為：

  ```python
  "hi5": max(x["c"]) if len(x["c"]) > 260 else None,
  ```

  ```python
  # 修正後：
  "hi5": max(x["c"][-1260:]) if len(x["c"]) >= 1260 else (max(x["c"]) if len(x["c"]) > 260 else None),
  ```

### Bug 4: `functions/api/gemini_ask.js:21` 單一字元美股代號被完全過濾
- **檔案路徑**：`functions/api/gemini_ask.js` 第 21 行
- **問題分析**：
  在 `pick()` 輔助函式中，代號與關鍵字過濾邏輯為：
  ```javascript
  keys = [r.s, ...(r.aliases || [])].filter(k => k && k.length >= 2);
  ```
  此處強制要求 `k.length >= 2`，導致紐約證券交易所（NYSE）歷史悠久的單一字母超級權值股（如花旗 `C`、福特 `F`、Visa `V`、Realty Income `O`）被完全濾除，使讀者在提問這些單一字母美股龍頭時，完全無法匹配最新相關新聞快訊。

  ```javascript
  // 修正後：
  keys = [r.s, ...(r.aliases || [])].filter(k => k && (k.length >= 2 || (k.length === 1 && /^[A-Z]$/.test(k))));
  ```
