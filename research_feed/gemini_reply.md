#### 2. `tools/site_twdesk.py` 行 66 與 70：數值為 0.0 時被判定為空值顯示 `"—"`
- **檔案路徑與行號**：`tools/site_twdesk.py:66, 70`
- **那一行在做什麼**：
  ```python
  def _f1(x) -> str:
      return "—" if not x else f"{x:.1f}"

  def _cash(x) -> str:
      return "—" if not x else f"{x:,.2f} 元"
  ```
- **為什麼有問題**：在 Python 中，`not 0.0` 與 `not 0` 的布林值均為 `True`。當某檔股票估值差距、偏離度剛好為 `0.0`，或配息金額為 `0.00 元` 時，會被錯誤格式化為 `"—"`（缺失），造成使用者誤以為資料遺失，而非實質數值為 0。
- **建議怎麼改**：
  明確檢查 `None`：
  ```python
  def _f1(x) -> str:
      return "—" if x is None else f"{x:.1f}"

  def _cash(x) -> str:
      return "—" if x is None else f"{x:,.2f} 元"
  ```
- **確定度**：高。

#### 3. `wsb/analytics/bankruptcy.py` 行 54：去年同期長期負債為 0 時引發除以零或無窮大漂移
- **檔案路徑與行號**：`wsb/analytics/bankruptcy.py:54`
- **那一行在做什麼**：
  ```python
  f["dgrowth"] = (df["ltd"] / df["ltd_yago"] - 1).clip(-1, 5)
  ```
- **為什麼有問題**：新創科技公司或無負債成長型公司在前期往往 `ltd_yago == 0`。當公司本期發行第一筆公司債時，分母為 0 會產生 `np.inf`，雖然有 `.clip(-1, 5)` 防守上限，但當兩期皆為 0 時，`0 / 0` 會產生 `np.nan`，使該特徵在缺失值填補時失去「零負債健康成長」的實質意義。
- **建議怎麼改**：
  ```python
  f["dgrowth"] = np.where(df["ltd_yago"] > 0, (df["ltd"] / df["ltd_yago"] - 1).clip(-1, 5), np.where(df["ltd"] > 0, 5.0, 0.0))
  ```
- **確定度**：中。

#### 4. `tools/site_intel.py` 行 36：跨午夜時區時戳解析缺少邊界健全性檢查
- **檔案路徑與行號**：`tools/site_intel.py:32-37`
- **那一行在做什麼**：
  ```python
  def _tpe(ts) -> str:
      try:
          return datetime.fromtimestamp(float(ts), timezone(timedelta(hours=8))).strftime("%m-%d %H:%M")
      except (TypeError, ValueError, OverflowError, OSError):
          return ""
  ```
- **為什麼有問題**：當 `ts` 傳入毫秒級 UNIX 時戳（如 13 碼 `1764230400000`）而非秒級時戳（10 碼）時，`datetime.fromtimestamp` 在 32 位元或特定平台上會引發 `OverflowError` 被捕獲而返回空字串 `""`，導致 SEC 8-K 或重大事件時間顯示為空白。
- **建議怎麼改**：
  ```python
  def _tpe(ts) -> str:
      try:
          v = float(ts)
          if v > 1e11:  # 毫秒轉秒
              v /= 1000.0
          return datetime.fromtimestamp(v, timezone(timedelta(hours=8))).strftime("%m-%d %H:%M")
      except Exception:
          return ""
  ```
- **確定度**：中。
