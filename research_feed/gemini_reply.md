### D-22：核心 PCE 3.3% 分項拆解與 AI 關聯性評估

### 卡片 1：#10-01 `valuation::估值與泡沫觀察`
- **原文呈現**：
  - 標題：「估值與泡沫觀察」

- **白話改法**：
  > 「現在股市的整體身價已經來到歷史上非常昂貴的水位。這就像去市場買菜，每一樣菜都被喊到天價。雖然昂貴不代表價格明天一定會掉，但只要有一點點壞消息，市場情緒就很容易出現大幅波動。新手面對這種環境，最重要的是保留充足的日常備用金，避免過度借錢參與波動。」

本小時依規則審查以下三個檔案：`tools/site_corpfund.py`、`tools/site_twbubble.py`、`wsb/analytics/event_clock.py`。

### 1. `tools/site_twbubble.py`
- **位置**：第 68–74 行
- **問題發現**：
  ```python
  f'<td class="r">{x["max"]:,.{x["dg"]}f}</td>'
  ```
  在走訪指標歷史統計清單時，直接將 `x["max"]` 進行浮點數格式化輸出。若外部來源在新增某個新興泡沫指標序列時，其歷史極值尚未完成歷史回溯計算而傳入 `None`，此行將拋出 `TypeError: unsupported format string passed to NoneType` 異常，導致整個台股泡沫頁面構建崩潰。
- **改進建議**：
  加入 `None` 安全防護判斷：
  ```python
  max_str = f'{x["max"]:,.{x["dg"]}f}' if x.get("max") is not None else "--"
  html.append(f'<td class="r">{max_str}</td>')
  ```

### 2. `wsb/analytics/event_clock.py`
- **位置**：第 112–116 行
- **問題發現**：
  ```python
  now = datetime.now()
  rec["recent"] = move_stats(symbol, market, str(now.year - 3) + "-01-01")
  ```
  此處計算近三年事件波動統計時，直接使用當前年份扣除 3 年並硬編碼拼接 `"-01-01"`，這會導致每年 1 月至 11 月期間實際取得的並非「滾動三年（Rolling 3 Years）」，而是 3 年到將近 4 年不等的非對稱樣本區間，扭曲了短期波動率統計。
- **改進建議**：
  改採滾動天數精確平移：
  ```python
  three_years_ago = (datetime.now() - timedelta(days=365 * 3)).strftime("%Y-%m-%d")
  rec["recent"] = move_stats(symbol, market, three_years_ago)
  ```
